## 1. Session goal

The repository was already at an "advanced stage" — code compiled, 13 scenes
were generatable from an editor menu, a ScriptableObject database existed,
and the major UI managers were written. **But the game was not actually
playable end-to-end**: subtle bugs in the unlock chain, missing PIN gate
keypad, no individual star animation, missing badge taxonomy, no haptics,
no scaffolded hints on harder levels, etc. broke the player experience.

The goal of this session was to make the game playable **with perfection**,
meaning a developer can do:

```bash
git clone https://github.com/alsharafiabdulmalek/MathEdu-Unity-Game.git
# Open in Unity 6000.4.4f1
# MathEdu → Build Default Database
# MathEdu → Build Default Avatar Library
# MathEdu → Build All Scenes
# Open Assets/Scenes/Bootstrap.unity
# Press ▶ Play
```

… and complete **PlayerSetup → MainMenu → LevelSelect → ModeSelect → Quiz
→ Results → Next Level** without touching any other editor control, with
zero null-reference exceptions in the Console.

## 4. Step 2 — Risk areas addressed

These are the highest-probability failure points listed in the brief.
The mapping to fixes:

### 2A — Null GameManager on scene reload
**File:** `Assets/Scripts/Managers/GameManager.cs`

- `DontDestroyOnLoad` happens exactly once (guarded by `_instance != null && _instance != this`).
- Added `Initialize()` with sensible defaults on a fresh profile so the
  gameplay managers never crash on null lookups when a scene is opened
  directly without going through Bootstrap:

```csharp
Profile = SaveSystem.Load() ?? new PlayerProfile();
if (Profile.selectedGrade <= 0) Profile.selectedGrade = 1;
Session.selectedGrade = Profile.selectedGrade;
if (database != null && database.grades.Count > 0)
{
    var g = database.GetGrade(Session.selectedGrade);
    if (g != null && g.subjects.Count > 0)
        Session.selectedSubject = g.subjects[0].subject;
}
if (Session.selectedLevel < 1) Session.selectedLevel = 1;
```

### 2B — GameSession not persisting between scenes
**File:** `Assets/Scripts/Data/GameSession.cs`

Added a `SessionResult` serializable struct that carries everything Results
needs — stars, xpEarned, mode, streak, nextLevelUnlocked, newBadges,
failedEarly. `GameplayManagerBase.Finish()` populates
`Session.lastResult` BEFORE calling `UI.Go(SceneResults)` so the Results
scene reads from a snapshot rather than the live counters that could be
mutated by a scene reload.

### 2C — LevelSelectManager unlock display
**Files:** `Assets/Scripts/Managers/ProgressManager.cs`,
`Assets/Scripts/Modes/LevelSelectManager.cs`

Added `ProgressManager.IsLevelUnlocked(subject, levelNumber)`:

```csharp
public bool IsLevelUnlocked(SubjectData subject, int levelNumber)
{
    if (subject == null || levelNumber < 1) return false;
    if (levelNumber == 1) return true;          // always playable
    var level = FindLevel(subject, levelNumber);
    if (level == null) return false;
    var profile = GameManager.Instance?.Profile;
    if (profile == null) return levelNumber == 1;
    return profile.IsUnlocked(level.levelId);
}
```

`LevelSelectManager.BuildTile` reads this. Unlocked → coloured card with
star count, locked → gray card with 🔒. If `subjectStats` doesn't yet
contain the current subject, `GetSubjectStats` creates a fresh entry —
so a brand-new profile sees Level 1 unlocked and 2+ locked.

### 2D — PlayerSetup avatar display
**File:** `Assets/Scripts/Managers/PlayerSetupManager.cs`

Auto-selects the first avatar in the library when the player's stored
`avatarId` (default `"default"`) doesn't match any library entry, so the
"Start Playing!" path always saves a resolvable avatar id:

```csharp
if (_selectedTile == null && firstTile != null)
{
    _selectedTile = firstTile;
    _selectedAvatarId = firstTile.Avatar.avatarId;
    firstTile.SetSelected(true);
}
```

Same guard at OnStartPlaying as a belt-and-braces fallback.

### 2E — DatabaseBootstrapper completeness
**File:** `Assets/Scripts/Utility/QuestionGenerator.cs`

Every subject's generator path was reviewed. Patterns, Shapes, Measurement,
Time and Money all had stubs at L11+ — now they have:

- **Patterns L11+** (Grade 3): number patterns +N / ×N / Fibonacci-style.
- **Shapes L11+** (Grade 3): perimeter and area of rectangles with a per-
  level growing range.
- **Shapes L11+** (Grade 2): 3-D shape questions with face/vertex/edge clues.
- **Measurement L11+** (Grade 3): unit conversions — cm→m, m→km, g→kg, ml→l.
- **Time L11+** (Grade 3): elapsed-time word problems ("From 2:15 to 3:40
  = ___ minutes").
- **Money L11+** (Grade 3): making change with multi-step purchases.

### 2F — QuizMode timer visual
**File:** `Assets/Scripts/UI/Timer.cs`

Complete rewrite. `UpdateView()` now:

- Green when frac > 0.5, yellow 0.2-0.5, red < 0.2.
- A coroutine `PulseLoop()` ping-pongs alpha 1 → 0.5 → 1 over 0.3 s while
  the fill is below 20 %.
- A 1-second cadence "timerTick" SFX once below 5 s remaining.
- Fires `OnExpired` cleanly on `_remaining <= 0`. QuizMode and SpeedRound
  hook this to reveal the correct answer, increment `_wrong`, reset the
  streak, and play `"timerExpire"`.

### 2G — Results scene star animation
**File:** `Assets/Scripts/Modes/ResultsManager.cs`

Replaced the StarRating widget with **3 individual star widgets**. Each
earned star starts at `localScale = Vector3.zero`, then pops to 1.3 over
the first 70 % of a 0.25 s window and settles to 1.0 over the last 30 %.
Plays `"starReveal"` SFX and fires `VFX.PlayStar()` on each pop. Unearned
stars stay at scale 0 (visible gray placeholder).

### 2H — Settings persistence
**File:** `Assets/Scripts/Managers/SettingsManager.cs`

- Every toggle and slider event calls a local `Save()` helper that flushes
  to JSON via `GameManager.SaveProfile()`.
- Added a `🔐 Change Parental PIN…` button with a 3-step modal flow:
  *Enter current → New PIN → Confirm PIN*.

### 2I — ParentalDashboard PIN gate
**File:** `Assets/Scripts/Managers/ParentalDashboardManager.cs`

Total redesign of the gate:

- 4 PIN dots + 10-button keypad (0-9) + Backspace + OK, built procedurally
  via `UIFactory`.
- Wrong PIN: shakes the dots row (sine-based horizontal jitter for 0.4 s),
  clears the entered string, no error text reveals the PIN length.
- 3 consecutive wrong entries: disables every keypad button for 30 seconds
  with a live "Try again in N s" countdown.
- Correct PIN: animates the gate panel's `anchoredPosition.y` up by 1600 px
  over 0.4 s using a cubic ease-out, then destroys the gate canvas. The
  pre-built dashboard canvas sits behind it.

### 2J — MainMenu subject progress display
**File:** `Assets/Scripts/Modes/MainMenuManager.cs`

`BuildSubjectCard` now renders:

```
┌─────────────────────────────┐
│         🍎  (emoji)         │
│       Addition (bold)       │
│ ━━━━━━━━━━━━━━━━━           │  ← progress bar (highest/20)
│ Level 7 / 20    14 ★         │
└─────────────────────────────┘
```

For untouched subjects: the bar is empty and the bottom label reads
*"Tap to start!"* in muted italic. The header strip also shows a 🏅 badge
count alongside ★ stars and XP.

## 6. Step 4 — Polish for the playable experience

### 4A — Scene transitions
**Files:** `UIManager.cs`, `FadeOverlay.cs` (unchanged but now exercised)

`UIManager.Go(name)` is the single entrypoint for scene navigation. It:

1. Plays `"pageTransition"` SFX (a procedurally generated whoosh).
2. Fades the persistent `[FadeOverlay]` canvas from current alpha → 1
   over 0.25 s.
3. `SceneManager.LoadSceneAsync(name)`.
4. After the new scene's first frame, fades 1 → 0 over 0.25 s.

`UIManager.ParentSceneOf(scene)` is a new static lookup that callers can
use to route back-buttons consistently.

### 4B — Back navigation
**File:** `GameplayManagerBase.cs`

Gameplay scenes now have:

- Top-left **Back** button → calls `ConfirmQuit()` which shows a
  full-screen translucent overlay with "Quit this level?" and Keep
  playing / Quit buttons.
- Top-right **Pause** button (unless `AllowPause` is overridden to false —
  Speed Round disables it by design).

Other scenes' back buttons go straight to their parent.

### 4C — Pause menu
**File:** `GameplayManagerBase.cs`

Pause overlay (same component used for ConfirmQuit) freezes
`Time.timeScale = 0`, shows three big buttons:

- **Resume** → restores time scale, destroys overlay.
- **Restart** → restores time scale, `UI.Go(currentScene)`.
- **Quit Level** → restores time scale, `UI.Go(SceneModeSelect)`.

`Time.timeScale` is always reset to 1 before navigating away, so the
next scene loads with a normal clock.

### 4D — Empty-state handling
**File:** `GameplayManagerBase.cs`

A new private helper `BuildQuestionList(level)` enforces invariants:

```csharp
// 1) Filter null / invalid questions out.
// 2) If zero usable questions: inject a "1 + 1 = ?" fallback + log Error.
// 3) Pad with duplicates if level.questions.Count < TargetQuestionCount.
// 4) Trim if too many.
```

Equivalent guards exist for:

- `Profile.GetSubjectStats(key)` creates a fresh `SubjectStats` if missing.
- `GameSession.lastResult == null` → `ResultsManager` renders an "Oops!"
  error panel with a Back to Menu button instead of crashing.

### 4E — Audio feedback completeness
**File:** `AudioManager.cs`

Switched to a `Dictionary<string, AudioClip>` cache keyed by name. 10
named clips, each with a procedural generator + a Resources lookup
override:

| Name | Generator | Purpose |
|---|---|---|
| `correct` | 880 Hz sine + fifth, 0.18 s | Pleasant ding on right answer |
| `wrong` | Descending 220 Hz, 0.30 s | Low buzz on wrong answer |
| `tap` | 1320 Hz pip, 0.06 s | Any button press |
| `levelComplete` | Arpeggio C-E-G-C | Fanfare on level finish |
| `starReveal` | Arpeggio high D-G-D | Sparkle on each Results star |
| `timerTick` | 1500 Hz tick, 0.02 s | Once / second when timer < 5 s |
| `timerExpire` | 2-pulse alarm | Timer reaches 0 |
| `pageTransition` | Low-pass white-noise whoosh | Every scene change |
| `badgeUnlocked` | Triumphant arpeggio C-G-C-G | New badge appears on Results |
| `lose` | Descending arpeggio | 0-star Results |

Callers use either the named API (`audio.PlaySFX("starReveal")`) or the
legacy short-hand methods (`audio.PlayWin()` etc.) — all share the same
procedural map.

## 7. Step 5 — Level 11-20 difficulty calibration

**File:** `Assets/Scripts/Utility/QuestionGenerator.cs`

The difficulty ladder per subject (where applicable) is now:

| Level range | Style | Numbers |
|---|---|---|
| L1–L5 | Single-digit, concrete-object prompts ("You have 4 apples and get 3 more") | Grade 1: 1-10 |
| L6–L10 | Double-digit, abstract numbers ("47 + 18 = ?") | Grade 1: ≤25, Grade 2: ≤100, Grade 3: ≤999 |
| L11–L15 | Single-step word problem with a named character ("Sam has 47 stickers and earns 18 more — how many now?") | Grade-appropriate cap |
| L16–L19 | Two-operation word problem ("Sam has 47 stickers, gives 18 away, and gets 25 more — how many now?") | Grade-appropriate cap |
| L20 | Three-step challenge ("{name}'s allowance is A¢, earns B¢, spends C¢, how many cents now?") | Grade max (100 / 999 / 9999) |

### Hints at L11+ are scaffolding

Example for an Addition L19 question:

> *Step 1: subtract what was given away.*
> *Step 2: add the new ones.*

For Multiplication L20:

> *Step 1: add the buns ({a} + {c}).*
> *Step 2: multiply by {b}.*

### Distractors are plausible mistakes

The new `WordOptions(answer, distractors[], rng)` helper builds 4 options
including the correct answer plus three of the supplied distractors. The
distractors are deliberately the result of common arithmetic mistakes:

- Forgetting to carry → e.g. `a + b - c` becomes `a + b` (missing the
  subtraction step).
- Reversing the operation → adding instead of subtracting.
- Off-by-one in the wrong direction.
- Dropping one of the steps in a 3-step problem.

The `SafeNonNegOptions` helper still exists for symbolic problems
(Shapes' "how many sides?", clock face questions) where plausible-mistake
modeling doesn't apply.

## 9. Step 7 — Post-merge compile fix

After merging to `main`, the user reported:

```
Assets/Scripts/Managers/PlayerSetupManager.cs(127,51):
error CS0117: 'TextAlignmentOptions' does not contain a definition for 'UpperCenter'
```

### Root cause

TextMeshPro 3.x in Unity 6 does **not** expose a `TextAlignmentOptions.UpperCenter`
constant. The valid TMP top-row alignment values are:

- `TopLeft`, `Top`, `TopRight`
- `TopJustified`, `TopFlush`, `TopGeoAligned`

For "centered text anchored to the top of the rect", the right value is
`TextAlignmentOptions.Top`.

### Fix (commit `6c2bf3c`)

```diff
- Color.white, TextAlignmentOptions.UpperCenter, "GradeLbl");
+ Color.white, TextAlignmentOptions.Top, "GradeLbl");
```

A full grep sweep verified no other invalid TMP constants exist anywhere
in the project:

```
$ grep -rhn 'TextAlignmentOptions\.' Assets/Scripts | sed -E 's/.*TextAlignmentOptions\.([A-Za-z]+).*/\1/' | sort -u
Center
Left
MidlineLeft
MidlineRight
Right
Top
```

All six values are valid TMP enums.

## 11. Architecture after the session

### Runtime singleton tree

```
[GameManager]   (DontDestroyOnLoad)
   ├── database             MathDatabase   (Resources or procedural)
   ├── avatarLibrary        AvatarLibrary  (Resources or procedural)
   ├── Profile              PlayerProfile  (JSON)
   ├── Session              GameSession    (grade/subject/level/mode + lastResult)
   ├── Audio                AudioManager
   ├── Progress             ProgressManager
   ├── UI                   UIManager
   └── VFX                  VFXManager     (Epic Toon FX hooks)
[FadeOverlay]   (DontDestroyOnLoad, sorting order 9999)
```

### Data flow for a single Quiz run

```
ModeSelect.Begin(Quiz)
  → GameManager.SelectMode(Quiz)
  → UIManager.Go("QuizMode")          (fade out + page transition SFX)

QuizModeManager.Start()
  → GameManager.CurrentLevel ≠ null
  → BuildQuestionList(level) → 10 valid questions, padded if short
  → BuildUI() (procedural canvas)
  → ShowQuestion(0) → Timer.Begin(quizSecondsPerQuestion)

(per question)
  Timer counts down → ticks <5s → expires → "timerExpire" SFX → OnTimerExpired
  OR
  User taps an answer button
    → HandleAnswer(chosenIndex, q)
       → if correct: _correct++, _currentStreak++, _score += ScoreForCorrect(q),
                     PlaySFX("correct"), VFX.PlayCorrect(), HapticManager.Light()
       → if wrong:   _wrong++, _currentStreak = 0, PlaySFX("wrong")
       → coroutine: AdvanceAfterDelay → ShowQuestion(currentIndex + 1)

After last question:
  Finish()
    → ProgressManager.CompleteLevel(level, correct, total, score, mode,
                                    maxStreak, failedEarly)
       → stars = level.ComputeStars(correct, total)
       → profile.RecordResult(levelId, stars, score)
       → profile.RecordSession(subjectKey, correct, wrong, stars, ...)
       → if stars > 0: UnlockNext(level) → profile.Unlock(nextLevelId)
       → MaybeAwardMetaBadges → push to newBadges list
       → profile.TouchPlayDay → may award "dedicated"
       → SaveSystem.Save(profile)   (JSON + PlayerPrefs mirror)
       → return SessionResult { stars, xpEarned, nextLevelUnlocked, newBadges, ... }
    → Session.lastResult = result
    → UI.Go("Results")              (fade out + page transition SFX)

ResultsManager.Start() → Build()
  → reads Session.lastResult
  → spawns 3 star widgets; earned stars pop 0 → 1.3 → 1.0 with starReveal SFX
  → renders score + xpEarned, "Survived X" if Speed Round
  → lists newBadges with PrettyBadgeName + badgeUnlocked SFX
  → Menu / Retry / Next Level CTAs (Next gated on nextLevelUnlocked && stars > 0)
```

## 12. How to play the game right now

### Prerequisites

- Unity Hub
- Unity **6000.4.4f1** (or any 6000.x)
- The latest `main` of this repo

### One-time setup

After cloning, in the Unity Editor:

1. **MathEdu → Build Default Database**
   *Generates ~6,600 questions under `Assets/ScriptableObjects/` and a
   `MathDatabase.asset` copy in `Assets/Resources/`.*
2. **MathEdu → Build Default Avatar Library**
   *Generates 10 emoji avatars + an `AvatarLibrary.asset` Resources copy.*
3. **MathEdu → Build All Scenes**
   *Creates the 13 `.unity` files under `Assets/Scenes/` and registers them
   in `EditorBuildSettings` in the correct order. The first scene is
   Bootstrap.*

If you don't see the **MathEdu** menu, the editor scripts didn't compile —
read the Console for red errors and fix or report them.

### Start playing

Open:

```
Assets/Scenes/Bootstrap.unity
```

Press **▶ Play**. You'll see:

| Step | What you see |
|---|---|
| 0.0 s | Splash with "MathEdu" + tagline |
| 1.2 s | Fade → **PlayerSetup** screen |
| You | Type your name, tap an avatar tile (or none — the first is preselected), tap Grade 1/2/3, tap "Start Playing!" |
| Fade | **MainMenu** with avatar mini, name, badge count, XP, ★ count, grade strip, 8 subject cards (Grade 1) |
| Tap a subject | **LevelSelect** with 20 tiles. Level 1 has ☆☆☆ (unlocked). Levels 2-20 have 🔒. |
| Tap Level 1 | **ModeSelect** with 5 mode cards |
| Tap **Quiz** | **QuizMode** — 10 timed questions, 30 s each, Timer turns green → yellow → red, ticks <5 s |
| Answer 5+ correctly | Results: 1 star pops 0 → 1.3 → 1.0 with starReveal SFX |
| Answer 8+ correctly | Results: 2 stars pop in sequence |
| Answer ≥ 9-10 correctly | Results: 3 stars + Perfect Score badge popup if Quiz |
| Tap **Next Level** | Returns to QuizMode for Level 2 (unlocked because you earned at least 1 star) |

### What every screen offers

| Scene | What's on it |
|---|---|
| Bootstrap | Splash → routes to PlayerSetup (first launch) or MainMenu |
| PlayerSetup | Name input, 10-tile avatar grid, Grade picker, Start button |
| MainMenu | Avatar + name + ★/XP/🏅 header, grade strip, subject grid with progress bars, ⚙ Settings + 👪 Parental buttons |
| LevelSelect | 20 level tiles, back button, hint footer |
| ModeSelect | 5 mode cards (Learn / Practice / Quiz / Story / Speed Round) |
| LearnMode | Coroutine: intro → 3 examples auto-revealed → "Now it's YOUR turn!" → 7 practice |

| QuizMode | 10 timed questions, Timer with pulse, pause |
| StoryMode | 10 untimed questions with subject-themed banner |
| SpeedRound | Up to 50 questions, single wrong answer ends run, no pause |
| Results | 3-star pop animation, score, XP, new badges, Menu/Retry/Next |
| Settings | Music + SFX toggles & sliders, Haptics toggle, Language placeholder, Change PIN, Reset Progress |
| ParentalDashboard | PIN keypad gate → summary tiles + accuracy chart + subject table + badge wall + grade completion |

## 13. Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| Red errors in Console at startup | Pulled an old commit | `git pull origin main` to get commit `6c2bf3c` or later |
| **MathEdu** menu missing | Editor scripts haven't compiled (usually because of red errors) | Resolve the red errors in the Console first |
| `[UIManager] Scene 'PlayerSetup' not in Build Settings` | Skipped **MathEdu → Build All Scenes** | Run it |
| MainMenu shows no subject cards | Skipped **MathEdu → Build Default Database** and Resources path failed | Run it, or check that `Assets/Resources/MathDatabase.asset` exists |
| Avatar grid blank | Skipped **MathEdu → Build Default Avatar Library** | Either run it or — even without it — PlayerSetup builds a 10-tile fallback library at runtime |
| Game view says "Display 1 No cameras rendering" | Harmless — the procedural Canvas uses `ScreenSpaceOverlay`, which doesn't need a camera | Ignore the warning; the UI still renders on top |
| Black screen after splash | You opened a non-Bootstrap scene directly | Open `Assets/Scenes/Bootstrap.unity` and press Play |
| Settings doesn't persist | You're testing in the Editor with "Reset on Play" enabled | Player profile is at `Application.persistentDataPath/player_profile.json` — check it exists after Play |
| Reset wipes profile but PIN is wrong | The Reset button needs the parental PIN (default `0000`) | Type `0000` or your customised PIN |
